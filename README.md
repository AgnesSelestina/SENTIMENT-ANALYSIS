 **What I did:**

* Performed text preprocessing (cleaning, lowercasing, removing stopwords and special characters)
* Converted textual data into numerical format using **TF-IDF Vectorization**
* Built a **Logistic Regression model** to classify sentiments
* Evaluated the model using accuracy, confusion matrix, and classification report

 **Results:**

* Successfully classified feedback into **Positive, Negative, and Neutral sentiments**
* Achieved high accuracy with effective text classification
* Identified patterns between student feedback and their performance

 **Tools & Technologies Used:**

* Python
* Pandas & NumPy
* NLTK (Natural Language Toolkit)
* Scikit-learn
* **Google Colab** (for implementation)

 **Applications:**
This model can be applied in:

*  Analyzing user reviews and feedback
*  Social media sentiment analysis (tweets, comments)
*  Product review analysis for businesses
*  Improving learning platforms based on student feedback

 Note: The dataset used was synthetically generated, making patterns more predictable compared to real-world textual data.
